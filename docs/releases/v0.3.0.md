Rustleblower v0.3.0 is the first stable release of the native OpenSnitch frontend.
It brings the recent daily-use improvements together while the OpenSnitch daemon
continues to own interception, enforcement and saved rules.

- Configure appearance, language, permission popups, startup, updates, history and
  optional integrations in one Settings window. Unsaved edits stay available
  while switching categories. Choose display density and installed palettes;
  English, French, German, Spanish and Japanese catalogues are included.
- Find connections and application rules with richer field filters and nested
  AND/OR expressions. History and rules can be scoped to cached or connected
  nodes, and application rules show their creation time with newest/oldest sorting.
- Select records across History, Statistics and Live pages, then copy or export
  the captured selection. The Live socket table adds meaningful sorting, saved
  columns and widths, and socket filters. Configurable table highlighting helps
  distinguish matching traffic and rules.
- Recover from missed permission prompts through configurable desktop notices
  that open Application rules. Temporary-rule catalogue preferences make expiry
  and remembered rule status clearer.
- Check official app and daemon releases manually or on an opt-in schedule.
  Optional VirusTotal reputation reports support domains, IP addresses and
  reported executable hashes; credentials and exclusions remain under your
  control. Permission decisions remain available while checks are running.
- Manage scheduled raw URL-to-file downloads separately from blocklists, with
  reviewed destinations and preservation of the last successful file. Blocklist
  updates gain configurable success/error notifications and safer recovery.
- Connect remote daemons through TCP, TLS or mutual TLS listeners. Use guided
  system-firewall statements with service/interface suggestions and review
  changes before the daemon applies them.
- Use a more compact dashboard, consistent History/Rules controls and clearer
  rule-creation feedback while retaining independent permission windows and
  close-to-tray behavior.

**Linux x86-64.** Download the **AppImage**, **Debian package** or **tar archive**,
and verify downloads with `SHA256SUMS`. Packages are built on Ubuntu 24.04 and
require glibc 2.39 or newer, an installed font, a supported graphics driver and a
Wayland or X11 desktop. Without FUSE, launch the AppImage with
`--appimage-extract-and-run`.

Install the OpenSnitch daemon separately and run Rustleblower as your desktop
user. For the default local connection, quit opensnitch-ui so it releases
`/tmp/osui.sock`; Rustleblower refuses to replace an existing socket. Existing
opensnitch-ui history is not imported. Full opensnitch-ui parity and broader
distribution testing remain ongoing.
