Rustleblower v0.4.0 adds experimental per-application network usage monitoring.
Open **Data usage** (`Ctrl+8`) and choose **Start monitoring** to authorize the
separate collector through your desktop's system password dialog.

- See live upload/download rates and total bytes uploaded/downloaded by each
  application during the current session. Search applications, sort by usage and
  browse results in bounded pages. Monitoring continues while the window is
  closed to the tray or another page is open.
- Group repeated short-lived commands such as curl under their executable path,
  retaining their usage after they exit. Paths are captured during network
  operations, so a command can finish between samples without losing its label.
- Start and stop collection directly from the UI. The desktop app remains
  unprivileged, while the independent Linux collector receives temporary elevated
  access. No KDE dependency, background service or passwordless rule is added.
- Keep the last totals visible when collection stops, and show unavailable rates,
  authorization cancellation and collector failures explicitly.

The **AppImage**, **Debian package** and **tar archive** include the collector.
AppImage startup copies it and its libraries to a private temporary directory
before authorization. Install `pkexec` and a desktop polkit authentication agent
to use monitoring. The temporary filesystem must allow executable files.

Monitoring needs a compatible Linux kernel with BTF, the required TCP/UDP tracing
hooks, BPF LSM enabled and executable/path filesystem kfuncs. Kernels missing
these features show an unavailable status; the remaining frontend features are
still usable. This release has been checked with kernel 7.2.9 on CachyOS;
broader kernel and distribution coverage remains ongoing.

Totals measure socket payload bytes, including local TCP/UDP traffic, rather
than interface or ISP billing bytes. Each monitoring session lasts at most one
hour. Start a new session afterwards; daily/monthly history and totals across
sessions are outside this first version. See the
[data usage guide](https://github.com/pelletiermaxime/rustleblower/blob/v0.4.0/docs/data-usage.md)
for requirements and measurement limits.

**Linux x86-64.** Verify downloads using `SHA256SUMS`. Packages are built on
Ubuntu 24.04 and require glibc 2.39 or newer, an installed font, a compatible
graphics driver and a Wayland or X11 desktop. Without FUSE, run the AppImage with
`--appimage-extract-and-run`.

Install the OpenSnitch daemon separately and run Rustleblower as your desktop
user. Quit opensnitch-ui before using the default local socket;
Rustleblower refuses to replace an existing `/tmp/osui.sock`. The daemon keeps
ownership of interception, enforcement and saved rules.
