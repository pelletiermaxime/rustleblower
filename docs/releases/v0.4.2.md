Rustleblower v0.4.2 refreshes its Rust dependencies and fixes the connected
fallback for unmatched traffic.

- While Rustleblower is connected, OpenSnitch denies unmatched traffic by
  default, matching opensnitch-ui. Existing rules, the daemon's saved
  configuration and Rustleblower's popup timeout preference are preserved.
- Update GPUI Kit to 0.9.1 and GPUI Fast to 0.1.14, along with the SQLite, SVG
  rendering, async runtime and gRPC dependencies.
- The README now has a shorter setup guide and links to detailed feature guides.

**Linux x86-64.** Verify downloads using `SHA256SUMS`. Packages require glibc
2.39 or newer, an installed font, a compatible graphics driver and a Wayland
or X11 desktop. Without FUSE, use `--appimage-extract-and-run`.

Install the OpenSnitch daemon separately and quit opensnitch-ui before starting
Rustleblower on the default local socket.
