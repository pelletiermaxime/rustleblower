This development prerelease expands Rustleblower's native frontend for the
existing OpenSnitch daemon. The interface is still unfinished, and full
opensnitch-ui feature parity remains in progress.

- Keep Rustleblower in the system tray, reopen it from the tray menu, and choose
  whether it starts when you log in. The main window remembers its size, mode
  and last page; System, Light and Dark appearance choices are saved.
- Answer connection prompts with direct **Allow forever** or **Allow for 12 hours**
  actions, clear whole-app or exact-destination scope, and application icons.
  Permission handling continues independently while other pages perform work.
- Browse and export daemon alerts, mark them read, and open Alerts from desktop
  notifications. Inspect live sockets, processes and node resources, including
  a shortcut from a retained connection to its current process.
- Review system-firewall chains, rules, expressions and profiles, with staged
  changes and daemon confirmation. Enable/disable sequences show their steps
  before applying. Support depends on the daemon's reported backend and format.
- Copy, create, rename, import and export rules across explicitly selected nodes.
  Review changes before applying, track per-node results and stop unsent work.
  Inclusive port ranges are available when the connected daemon supports them.
- Manage blocklist subscriptions from a usable empty catalogue: add URLs, test
  them before saving, refresh or pause downloads, inspect status and retained
  data, and configure groups and associated application rules. Bulk changes and
  configuration imports have a review step. Counts and units can inherit
  independently from defaults; invalid dependent limits are refused.
- Keep History search, filters, sorting and column widths across launches, set
  local history preferences, and optionally remember a node's confirmed paused
  interception state across reconnects. History and retained work remain bounded.
- Use the new colour Ferris-and-whistle application and tray icons, with drawings
  tailored to small tray sizes.

**Linux x86-64 only.** Packages are built on Ubuntu 24.04 and require glibc 2.39
or newer, an installed font, a supported graphics driver and a Wayland or X11
desktop. Install the OpenSnitch daemon separately. The local Unix-socket
integration retains the original 1.7.2 protocol compatibility target; newer
features are checked against pinned OpenSnitch source, and some controls require
newer daemon capabilities. Remote TCP/TLS connections are not implemented.

Download the **AppImage**, **Debian package** or **tar archive**, and verify it with
`SHA256SUMS`. Without FUSE, launch the AppImage with `--appimage-extract-and-run`.
Run Rustleblower as your desktop user. Quit opensnitch-ui first so it releases
`/tmp/osui.sock`; Rustleblower refuses to replace an existing socket. The daemon
continues to own enforcement and saved policy. Old opensnitch-ui history is not
imported.

Upgrading preserves existing numeric subscription limits as absolute values.
New native subscription backups use version 2 and still accept version 1.
Reimport the original OpenSnitch configuration to recover count/unit inheritance
choices that an older Rustleblower import had already converted to absolute values.

This is an early prerelease for testing. UI consistency, remaining feature parity
and broader distribution testing are still pending. Isolated protocol, storage,
GPU/input and package checks do not prove every real daemon's enforcement or a
memory improvement over the Qt UI.
