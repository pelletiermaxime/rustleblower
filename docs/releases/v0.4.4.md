Rustleblower v0.4.4 adds in-app updates for the Linux x86-64 AppImage.
Install this release manually to get the updater. Future stable updates can
download in the background.

1. Open **Settings → Updates** and select **Rustleblower** with prereleases off.
2. Enable **Check automatically** and **Download stable Rustleblower AppImage
   updates**, then save. **Check now** can also start a download.
3. Choose **Restart to update** after verification. Rustleblower shuts down its
   backend and releases the OpenSnitch socket before launching the replacement.
   If the replacement fails during startup and exits, Rustleblower restores the
   previous AppImage.

The updater checks the downloaded AppImage against the release's `SHA256SUMS`.
The AppImage directory needs to be writable. Debian package and tarball updates
use the release page.

**Linux x86-64.** Packages require glibc 2.39 or newer, an installed font, a
compatible graphics driver and a Wayland or X11 desktop. Without FUSE, use
`--appimage-extract-and-run`. Install the OpenSnitch daemon separately and quit
opensnitch-ui before starting Rustleblower on the default local socket.
