Rustleblower for Linux x86-64

Requires Ubuntu 24.04 or a compatible Linux distribution (glibc 2.39 or newer),
a working graphics driver, a Wayland or X11/XWayland desktop, and access to an existing
OpenSnitch daemon. Install the daemon separately; this release contains only its UI.

Debian package:
  sudo apt install ./rustleblower_@VERSION@_amd64.deb
  Launch Rustleblower from your applications menu or run: rustleblower

AppImage:
  chmod +x rustleblower-@VERSION@-linux-x86_64.AppImage
  ./rustleblower-@VERSION@-linux-x86_64.AppImage
  If FUSE mounting is unavailable:
  ./rustleblower-@VERSION@-linux-x86_64.AppImage --appimage-extract-and-run
  Application libraries are bundled. glibc, fonts, Wayland libraries,
  the Vulkan/EGL graphics driver stack, and the OpenSnitch daemon come from your system.
  Bundled library notices are inside usr/share/doc/<library-package>/copyright;
  use --appimage-extract to inspect the AppImage contents.

Tar archive:
  Extract the archive, open a desktop terminal in the extracted directory,
  and run: ./rustleblower
  Optional installation: install -Dm755 rustleblower ~/.local/bin/rustleblower

The archive uses system libraries. On Ubuntu/Debian, install the runtime
libraries if they are missing:
  sudo apt install libfontconfig1 libfreetype6 libxcb1 libxkbcommon0 \
    libxkbcommon-x11-0 libvulkan1 libegl1 libwayland-client0 \
    libwayland-cursor0 libwayland-egl1

You also need an installed font and a GPU driver usable by Vulkan or EGL.
The Debian package installs library dependencies automatically.

User guide and troubleshooting:
  https://github.com/pelletiermaxime/rustleblower#readme

when installed from the Debian package.

Switching from opensnitch-ui:
  Quit opensnitch-ui first so it releases /tmp/osui.sock, then launch Rustleblower.
  Rustleblower refuses to replace an existing socket. Do not run it as root.
  Quit Rustleblower through its Quit button; closing its window minimizes it.
  History starts with newly received reports; existing UI history is not imported.

This first development release has an unfinished interface. Remote TCP/TLS,
system-firewall editing, tray integration and full opensnitch-ui parity are pending.
