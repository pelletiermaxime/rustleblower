# Rustleblower feature map

Read the feature before selecting a proof. Listed entry points are a coverage
contract, not a blanket claim that every path has native proof. Each file states
the tested boundary. Preserve the action and observable result with each report.

- [Permissions](permissions.md): separate permission window, saved matching/fallback defaults, X11 placement, pointer/keyboard countdown review, replies, deadlines, overload, and cancellation.
- [Checksum changes](checksums.md): reported-vs-saved warning, bounded review, selected/all acknowledged updates, stop/failure and independent permission decisions.
- [History](history.md): typed filters, configurable Kit table/global sorting, bounded CSV/JSON export, search/paging, persistent details, copy/rule creation and incomplete-history feedback.
- [Application rules](rules.md): catalogue pages, full editor, duplicate, import/export, cross-page selection, bulk actions, acknowledged changes and failure handling.
- [Statistics](statistics.md): daemon-reported category counters, bounded persistent cache, node/search/sort/chart, frozen paging, local reset, exact history drilldown and CSV/JSON/clipboard.
- [Nodes](nodes.md): independent sessions, cached metadata, per-node rules/interception/configuration, scoped reconnects and command uncertainty.
- [Daemon preferences](daemon-preferences.md): typed settings, preserved unknown values, bounded changed-field review, complete JSON, acknowledged save and failure recovery.
- [Connection and lifecycle](connection.md): local daemon status, alerts, reconnects, socket ownership, minimize, and explicit quit.
- [Resource limits](resources.md): bounded ingestion, retention, database failure isolation, and measurement.
