# Rustleblower feature map

Read the feature before selecting a proof. Listed entry points are a coverage
contract, not a blanket claim that every path has native proof. Each file states
the tested boundary. Preserve the action and observable result with each report.

- [Permissions](permissions.md): separate permission window, saved matching/fallback defaults, X11 placement, pointer/keyboard countdown review, replies, deadlines, overload, and cancellation.
- [Checksum changes](checksums.md): reported-vs-saved warning, bounded review, selected/all acknowledged updates, stop/failure and independent permission decisions.
- [History](history.md): typed filters, configurable Kit table/global sorting, bounded CSV/JSON export, search/paging, persistent details, copy/rule creation and incomplete-history feedback.
- [Application rules](rules.md): catalogue pages, full editor with session-gated inclusive port ranges, duplicate, import/export, cross-page selection, bulk actions, acknowledged changes and failure handling.
- [Statistics](statistics.md): daemon-reported category counters, bounded persistent cache, node/search/sort/chart, frozen paging, local reset, exact history drilldown and CSV/JSON/clipboard.
- [Nodes](nodes.md): independent sessions, cached metadata, per-node rules/interception/configuration, opt-in saved pause/restart restoration, scoped reconnects and command uncertainty.
- [Daemon preferences](daemon-preferences.md): typed settings, preserved unknown values, bounded changed-field review, complete JSON, acknowledged save and failure recovery.
- [Connection and lifecycle](connection.md): local daemon status, alerts, reconnects, socket ownership, close to tray, restoration/fallback, explicit quit, and staged per-user startup preferences with AppImage-aware launch paths, and bounded main-window geometry/mode/last-page restoration.
- [Resource limits](resources.md): bounded ingestion, retention, database failure isolation, and measurement.

- [Daemon alerts](alerts.md): bounded persistent text/typed payloads, node/severity/search/read filters, frozen paging, reviewed local deletion, CSV/JSON/clipboard and independent permissions.

- [Desktop notifications](desktop-notifications.md): bounded worker, urgency, saved toggle, replacement, Open alerts restoration and private D-Bus verification.

- [Live inspection](live.md): daemon socket/process/resource tasks, filters, bounded latest snapshots, stop lifecycle and independent permissions.

- [History preferences](history-preferences.md): reviewed transactional retention, idle cleanup, persisted manual/automatic refresh and CLI overrides.

- [Master reference and new parity gaps](../../../../docs/upstream-reference.md): pinned a1353848/1.9.0, native subscription manager, inclusive port ranges and remaining runtime gaps, list matching, multi-node operations and persisted pause; all remain in the full port scope.

- [System firewall](firewall.md): partial port with staged chain/rule/expression/value forms, bounded browsing, complete reload, stale guards, file/imported-profile interchange and accepted/report provenance; built-in policy presets and acknowledged enable/disable are implemented; backend helpers and broader native proof remain pending.

- [Required final UI/UX consistency pass](../../../../docs/ui-consistency-plan.md): shared layouts/edit/action states, meaningful whole-dataset table sorting, semantic colors and whole-app rendered/input comparison. Pending after feature implementation; required before goal completion.

- [Blocklist subscriptions](subscriptions.md): direct empty/add/edit/default controls, bounded independent HTTP/storage worker, conditional refresh/cancel/last-good data, global sorting/paging and owned-network verification; canonical data, group/all collection controls, reviewed membership and UID-scoped local-node rules are implemented; reviewed bulk configuration, native/OpenSnitch transfer, per-ID extra fields and complete-catalogue replacement are implemented with atomic stale/error refusal; pre-save URL diagnostics now have bounded HEAD/GET/hosts-sample/cancel controls; legacy coupling, notifications and other parity work remain pending. Metadata-archive recovery tools are a separate Rustleblower improvement.

- [Multi-node rules](rule-distribution.md): reviewed selected/full-filter copies, direct unsaved drafts and ordered rename, file/directory/captured-clipboard imports, explicit destinations/conflicts, exact wire values, per-node ACK/results, Stop/retry and generation guards; reviewed all/filter disk-backed folder export supports offline caches and complete publication. Broader native proof remains pending.

- [Appearance](appearance.md): native Kit System/Light/Dark colors, reset/reload, bounded async file persistence and retained editor/prompt state; native system-change callbacks, custom themes, density and final whole-app visuals remain separate.
